# InfraAgent Landing Page

A modern, futuristic landing page for InfraAgent - an AI-powered DevOps automation engine.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React Icons

## Project Structure

```
src/
  components/     # Reusable components
  sections/       # Page sections
  styles/         # Global styles
  App.jsx         # Main app component
  main.jsx        # Entry point
```
